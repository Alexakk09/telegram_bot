# Telegram Weather & Time Bot

A Go-based Telegram bot that provides weather forecasts, time information, and location-based services through Telegram.

## Features

- 🌦️ Weather information
- 🌍 Location and geocoding support
- 🕐 Time and timezone information
- 🤖 Telegram bot interface
- 🐳 Docker support
- 🗄️ PostgreSQL integration
- 🔐 Environment-based configuration
- 🌐 External API integration

## Tech Stack

- **Go**
- **Telegram Bot API**
- **PostgreSQL**
- **Docker**
- **REST APIs**
